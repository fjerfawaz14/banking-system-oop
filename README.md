# Banking System Using OOP

## About the Project
Banking System is a Python project that demonstrates the use of Object-Oriented Programming (OOP) to manage bank accounts, transactions, and user data.

The project focuses on organizing code using classes and objects to make the program easier to understand and maintain.

## Project Objectives
- Practice Object-Oriented Programming in Python.
- Organize banking operations using classes and objects.
- Improve Python programming and problem-solving skills.
- Build a simple banking system as a practical programming project.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)

## How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in your code editor.
4. Run the following command in the terminal:

```bash
python main.py
```
